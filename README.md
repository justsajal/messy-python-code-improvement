# Messy Python Code Improvement

This project demonstrates how a hard-to-read Python script can be refactored into a clearer version.

## Files
- `messy_version.py`: deliberately unstructured example for comparison
- `improved_version.py`: refactored version with functions, meaningful names, validation, and a main guard

## Run the improved version
```bash
python improved_version.py
```

Enter numbers separated by spaces, for example: `12 4 8 3`.

## Improvements made
- Replaced unclear names with descriptive names
- Split work into small functions
- Added input validation
- Used a main function and `if __name__ == "__main__"`
- Kept output consistent and readable
